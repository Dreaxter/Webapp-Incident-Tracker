# Security Policy

## Supported Versions

The following versions of Company Incident Tracker are currently supported with security updates.

| Version | Supported |
| ------- | ---------- |
| 1.2.x   | ✅ |
| < 1.2   | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### Reporting Method

Please contact:

- Gerben Rohof

Include the following information when reporting:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Screenshots or proof-of-concept (if applicable)

---

## Response Process

Reported vulnerabilities will be reviewed as quickly as possible.

Possible outcomes include:

- Vulnerability accepted and patched
- Vulnerability acknowledged for future update
- Vulnerability declined if determined non-applicable

---

## Security Recommendations

For production deployments, it is recommended to:

- Use environment variables for secrets and passwords
- Enable HTTPS
- Restrict file upload types
- Regularly back up incident data
- Keep Python dependencies updated
- Restrict public access where appropriate

---

## Scope

This policy applies to:

- Company Incident Tracker
- Associated deployment configurations
- Official releases published by Gerben Rohof
